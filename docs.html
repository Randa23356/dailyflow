Dokumentasi DailyFlow

Selamat datang di dokumentasi resmi DailyFlow — aplikasi produktivitas modern untuk mengelola tugas harian dan membangun kebiasaan positif.

Smart Todos

Kelola tugas dengan prioritas, deskripsi, dan tanggal jatuh tempo.

Habit Tracking

Bangun kebiasaan positif dengan streak harian dan jadwal fleksibel.

Smart Notifications

Pengingat cerdas untuk memastikan Anda tidak melewatkan apapun.

Dark Mode

Tampilan gelap yang elegan, mengikuti preferensi sistem Anda.

Versi Saat Ini

DailyFlow v1.0.0 · Tersedia untuk Android · Gratis tanpa iklan

Setup

Instalasi

DailyFlow tersedia sebagai file APK untuk Android. Ikuti langkah berikut untuk menginstall aplikasi:

1

Download APK

Klik tombol Download Gratis di website atau unduh langsung dari halaman download. Pilih versi sesuai arsitektur perangkat Anda.

2

Aktifkan Sumber Tidak Dikenal

Buka Pengaturan → Keamanan → Instal aplikasi tidak dikenal, lalu aktifkan izin untuk browser atau file manager Anda.

3

Install APK

Buka file APK yang sudah didownload menggunakan file manager, lalu tap Install dan ikuti petunjuk di layar.

4

Buka Aplikasi

Setelah instalasi selesai, buka DailyFlow dari launcher. Izinkan notifikasi saat diminta agar fitur pengingat berfungsi optimal.

Tips

Pilih APK arm64-v8a untuk perangkat 64-bit modern (direkomendasikan). Gunakan armeabi-v7a untuk perangkat lama atau 32-bit.

Fitur

Dashboard

Dashboard adalah halaman utama DailyFlow yang memberikan ringkasan aktivitas produktivitas Anda hari ini secara menyeluruh.

Apa yang ditampilkan di Dashboard?

  • Ringkasan Todo Hari Ini — jumlah tugas selesai vs total
  • Habit Streak — kebiasaan yang perlu diselesaikan hari ini
  • Motivational Quote — kutipan motivasi harian
  • Progress Overview — visual progress mingguan

Navigasi Antar Halaman

Gunakan navigation bar di bagian bawah layar untuk berpindah antara Dashboard, Todos, Habits, dan Settings. Anda juga bisa swipe kiri/kanan untuk navigasi lebih cepat.

Manajemen Todos

Fitur Todos memungkinkan Anda membuat, mengelola, dan menyelesaikan tugas-tugas harian dengan efisien.

Fitur Todos

  • Buat tugas dengan judul dan deskripsi opsional
  • Atur prioritas: Tinggi, Sedang, atau Rendah
  • Tetapkan tanggal jatuh tempo untuk setiap tugas
  • Tandai tugas sebagai selesai dengan satu ketukan
  • Filter tugas berdasarkan status (semua/aktif/selesai)
  • Swipe untuk menghapus tugas dengan cepat
Prioritas Warna Keterangan
🔴 Tinggi Merah Tugas mendesak atau penting
🟡 Sedang Kuning Tugas normal, perlu perhatian
🟢 Rendah Hijau Tugas opsional atau tidak mendesak

Habit Tracking

Bangun kebiasaan positif secara konsisten dengan sistem habit tracking yang cerdas dan memotivasi.

Cara Kerja Habit

  • Buat habit dengan nama, deskripsi, dan ikon pilihan
  • Atur jadwal pengulangan: harian, mingguan (pilih hari), atau weekday
  • Set pengingat notifikasi di waktu tertentu
  • Centang habit setiap hari untuk menjaga streak Anda
  • Pantau streak terpanjang dan total penyelesaian

Jaga Streak Anda!

Jika Anda melewatkan satu hari pada habit harian, streak Anda akan direset ke 0. Aktifkan notifikasi pengingat agar tidak terlewat.

Notifikasi

DailyFlow menggunakan notifikasi lokal untuk mengingatkan Anda tentang habit dan tugas tanpa memerlukan koneksi internet.

Jenis Notifikasi

  • Habit Reminder — pengingat berdasarkan waktu yang Anda set saat membuat habit
  • Due Date Reminder — notifikasi saat todo mendekati tanggal jatuh tempo

Izin Notifikasi

Pastikan izin notifikasi sudah diberikan ke DailyFlow. Jika notifikasi tidak muncul, periksa di Pengaturan Perangkat → Aplikasi → DailyFlow → Notifikasi.

Panduan

Cara Membuat Todo

1

Buka halaman Todos

Tap ikon Todos di navigation bar bawah.

2

Tap tombol +

Tap tombol FAB (floating action button) berwarna biru di pojok kanan bawah.

3

Isi detail tugas

Masukkan judul, deskripsi (opsional), pilih prioritas, dan set tanggal jatuh tempo jika diperlukan.

4

Simpan

Tap tombol Simpan untuk menambahkan tugas ke daftar.

Cara Membuat Habit

1

Buka halaman Habits

Tap ikon Habits (daun) di navigation bar bawah.

2

Tap tombol +

Tap FAB di pojok kanan bawah untuk membuka form pembuatan habit.

3

Konfigurasi habit

Masukkan nama habit, deskripsi, pilih ikon, atur jadwal pengulangan, dan aktifkan notifikasi jika diinginkan.

4

Simpan & Mulai

Tap Simpan. Habit akan muncul di halaman Habits dan siap untuk diceklis hari ini.

Mengubah Tema

DailyFlow mendukung Light Mode, Dark Mode, dan mengikuti tema sistem perangkat Anda secara otomatis.

1

Buka Settings

Tap ikon Settings (roda gigi) di navigation bar bawah.

2

Tap "Theme"

Di bagian Appearance, tap item Theme untuk membuka dialog pilihan tema.

3

Pilih tema

Pilih Light, Dark, atau System Default sesuai preferensi Anda.
